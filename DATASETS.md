# See the data behind the two demos

Both demo scripts generate synthetic data when they run. [`visualize_datasets.py`](visualize_datasets.py) repeats their dataset-generation and train/test-split settings, then saves a plot that learners can inspect before studying the models. The visualizer does not train models or connect to MLflow.

## Run it

The existing `.venv` already has Matplotlib and scikit-learn. From the project root:

```bash
cd /home/allen/mlflow-kubeflow-handson
source .venv/bin/activate
python3 visualize_datasets.py
```

The command prints the number of training and test examples in each class and saves **`datasets.png`** in this folder. To open a plot window as well, run `python3 visualize_datasets.py --show` in a graphical session. To save elsewhere, use `--output path/to/my-plot.png`. The MLflow server is not needed for this visualization.

## Read the three panels

| Panel | What it shows | Connection to training |
| --- | --- | --- |
| **ML: classification data** | A 2D PCA projection of the 1,000 rows with 12 features from `mlflow_ml_demo.py`. | The logistic-regression models train on all **12 original features**. PCA is used only to make a 2D picture; overlapping dots in this projection do not show everything the models can use. |
| **DL: circles before scaling** | The two original coordinates from the 1,200 rows generated by `make_circles`. | This shows the noisy inner and outer circles that the neural network must separate. |
| **DL: circles after scaling** | The same circle points after `StandardScaler` centers and scales each coordinate. | These are the feature values converted to tensors and passed to `CircleNet` in `pytorch_dl_demo.py`. |

In every panel, **blue = class 0**, **orange = class 1**, **filled dots = training examples**, and **hollow dots = held-out test examples**. The script uses the same random seeds and stratified 80/20 splits as the demos: **800 train / 200 test** for ML and **960 train / 240 test** for DL. Stratification keeps the class proportions similar across the two parts of each dataset.

PCA is fitted on the ML training rows only, then used to project the ML test rows. Likewise, `StandardScaler` is fitted on the DL training rows only, then applied to the DL test rows. Fitting these transformations on training data avoids letting the held-out test data influence them.

The plot displays the **true labels**, not model predictions. It helps explain what the models receive and what they are asked to predict; the accuracy and F1 scores are measured separately in the demo scripts and recorded in MLflow.
